2. Hypothesis testing

  • Null hypothesis (H0): no difference / no association. Alternative (H1): there is a difference.
  • p-value: probability of getting a result at least as extreme as observed if H0 were true. It is not the probability that H0 is true.
  • α (significance level): usually 0.05. If p < α, reject H0.
  • Type I error (α): false positive – concluding a difference exists when it does not. Type II error (β): false negative. Power = 1 − β (usually 80%).
  • 95% Confidence interval: range of plausible values for the true population value. If a CI for a difference excludes 0 (or for a ratio excludes 1), the result is significant at 5%.
  • Statistical vs clinical significance: with large samples, tiny useless differences become significant. Always report the effect size and its CI, not just p.

3. Parametric vs non-parametric

Parametric tests (t-test, ANOVA, Pearson) assume approximately normal data and compare means. Non-parametric tests (Mann-Whitney, Kruskal-Wallis, Spearman) use ranks, make fewer assumptions and compare distributions / medians. Use non-parametric tests for skewed data with small samples, ordinal scores, or outliers.

5. Multiple comparisons

Each test at α = 0.05 has a 5% false-positive risk. Doing 20 tests gives a ~64% chance of at least one false positive (\(1-0.95^{20}\)). Post-hoc tests (Tukey, Bonferroni, Holm, Dunn) control this.

Descriptive statistics

Purpose: summarise a numeric variable – its centre (mean, median) and spread (SD, IQR). Every thesis "Table 1" is built from these.

Formulae

\[\bar x = \frac{\sum x_i}{n}\qquad SD = \sqrt{\frac{\sum (x_i-\bar x)^2}{n-1}}\qquad SE = \frac{SD}{\sqrt n}\qquad 95\%\,CI = \bar x \pm t_{0.975,n-1}\,SE\]

Background – why n−1?

The sample mean is calculated from the same data, so deviations from it are slightly smaller than deviations from the true population mean. Dividing by n−1 (Bessel's correction, "degrees of freedom") makes the sample variance an unbiased estimate of the population variance.

SD vs SE

SD describes variability between individuals. SE describes the precision of the mean – it shrinks as n grows. Report mean ± SD for describing patients; use SE/CI for inference.

Mean or median?

Normal (symmetric) data → mean ± SD. Skewed data (e.g. CRP, hospital stay, income), outliers or ordinal scores → median (IQR). Skewness beyond ±1 or a significant Shapiro-Wilk test suggests skew. A useful clue: if SD > mean/2 for a variable that cannot be negative, it is probably skewed.

Frequency table and proportions

Purpose: count how many subjects fall into each category (e.g. sex, blood group) and give percentages with 95% CI.

Formula

\[p = \frac{x}{n}\qquad \text{Wald 95\% CI: } p \pm 1.96\sqrt{\frac{p(1-p)}{n}}\]

MAMC BioStat reports the exact Clopper-Pearson interval (based on the binomial distribution), which is accurate even for small n or proportions near 0 or 1, where the Wald interval fails.

Tips

  • Report as n (%), e.g. "Males 64 (53.3%)".
  • State the denominator if there are missing values ("valid %").

Normality testing (Shapiro-Wilk, Q-Q plot)

Purpose: decide whether parametric tests (t-test, ANOVA, Pearson) are appropriate.

Hypotheses

H0: data come from a normal distribution. p < 0.05 → evidence of non-normality.

Formula

\[W = \frac{\left(\sum_{i=1}^n a_i x_{(i)}\right)^2}{\sum_{i=1}^n (x_i-\bar x)^2}\]

x(i) are the ordered values; ai are weights derived from the expected values of normal order statistics. W is essentially the squared correlation between the data and the values expected under normality; W = 1 means a perfect fit.

Background / caveats

  • Shapiro-Wilk is the most powerful common normality test for n < 2000.
  • Small samples: low power – a non-significant result does not prove normality.
  • Large samples: trivial departures become significant. Thanks to the Central Limit Theorem, means of samples with n ≥ 30 per group are approximately normal anyway – look at the Q-Q plot and skewness.
  • For t-tests check normality within each group; for paired t-test check the differences; for regression check the residuals.

One-sample t-test

Purpose: compare the mean of one sample with a known / reference value. Example: Is the mean Hb of MAMC hostel students different from 13 g/dL?

Hypotheses

H0: μ = μ0; H1: μ ≠ μ0.

Assumptions

  • Numeric data, independent observations.
  • Approximately normal (or n ≥ 30).

Formula

\[t = \frac{\bar x - \mu_0}{s/\sqrt n},\qquad df = n-1\]

Steps

  1. Compute the sample mean and SD.
  2. Compute SE = s/√n.
  3. Compute t = (difference)/SE.
  4. Compare with the t distribution with n−1 df to get p.

Background

W.S. Gosset ("Student", 1908, Guinness brewery) showed that when the SD is estimated from a small sample, the ratio follows a t distribution, which has heavier tails than the normal distribution. As n increases, t approaches the normal (z) distribution.

If assumptions fail

Use the Wilcoxon signed-rank test (one-sample).

Independent-samples (unpaired) t-test

Purpose: compare means of a numeric outcome between two independent groups. Example: Mean SBP after 12 weeks in Drug A vs Drug B.

Hypotheses

H0: μ1 = μ2; H1: μ1 ≠ μ2.

Assumptions

  • Independent observations; each subject in only one group.
  • Outcome approximately normal in each group (or n ≥ 30 per group).
  • Equal variances (Student) – checked by Levene's test. If violated, use Welch's t-test.

Formulae

\[s_p = \sqrt{\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}},\qquad t = \frac{\bar x_1 - \bar x_2}{s_p\sqrt{\frac1{n_1}+\frac1{n_2}}},\qquad df = n_1+n_2-2\] Welch: \[t = \frac{\bar x_1-\bar x_2}{\sqrt{\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}}},\qquad df = \frac{\left(\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1}+\frac{(s_2^2/n_2)^2}{n_2-1}}\] Effect size: \[d = \frac{\bar x_1-\bar x_2}{s_p}\quad(0.2\text{ small},\;0.5\text{ medium},\;0.8\text{ large})\]

Background

The t statistic is a "signal-to-noise" ratio: the difference between means (signal) divided by its standard error (noise). Many statisticians now recommend Welch's test by default because it performs well whether or not variances are equal. Levene's test (Brown-Forsythe version, using deviations from the median) is used here as it is robust to non-normality.

If assumptions fail

Skewed data with small samples → Mann-Whitney U test. 3+ groups → ANOVA.

Paired t-test

Purpose: compare two measurements on the same subjects (before/after treatment, left vs right eye) or matched pairs.

Hypotheses

H0: mean difference μd = 0.

Assumptions

  • Pairs are independent of each other.
  • The differences are approximately normal.

Formula

\[d_i = x_{2i}-x_{1i},\qquad t = \frac{\bar d}{s_d/\sqrt n},\qquad df = n-1\]

Background

The paired test is simply a one-sample t-test on the differences. Because each subject acts as his/her own control, between-person variability is removed, making the test much more powerful than an unpaired test. Using an unpaired test on paired data is a common thesis error.

Data layout

One row per subject, two columns (e.g. SBP_baseline, SBP_week12).

If assumptions fail

Wilcoxon signed-rank test (paired).

One-way ANOVA

Purpose: compare means of a numeric outcome across 3 or more independent groups. Example: SBP in Drug A, Drug B and Placebo.

Why not multiple t-tests?

Three t-tests at α = 0.05 inflate the overall false-positive rate to about 14%. ANOVA tests all groups in one step.

Hypotheses

H0: μ1 = μ2 = ... = μk; H1: at least one mean differs.

Assumptions

  • Independent observations.
  • Normality within each group.
  • Homogeneity of variances (Levene). If violated → Welch's ANOVA + Games-Howell type post-hoc.

Formulae

\[SS_B = \sum_j n_j(\bar x_j - \bar x)^2,\quad SS_W = \sum_j\sum_i (x_{ij}-\bar x_j)^2\] \[MS_B = \frac{SS_B}{k-1},\quad MS_W = \frac{SS_W}{N-k},\quad F = \frac{MS_B}{MS_W},\quad \eta^2 = \frac{SS_B}{SS_T}\]

Background

Developed by R.A. Fisher (1920s). ANOVA compares two estimates of variance: one from the spread of group means (between) and one from the spread within groups. If H0 is true, both estimate the same population variance and F ≈ 1. A large F means the group means are more spread out than chance would produce.

Post-hoc tests

A significant F only says "some difference exists". Tukey's HSD compares all pairs while controlling the family-wise error rate. If variances are unequal, use the pairwise Welch tests (Holm-adjusted).

If assumptions fail

Kruskal-Wallis test.

Two-way (factorial) ANOVA

Purpose: study the effect of two factors and their interaction on a numeric outcome. Example: effect of Drug group and Sex on SBP – does the drug work differently in men and women?

Model

\[y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \varepsilon_{ijk}\]

Interpretation

  • Main effect A: does the outcome differ across levels of A (averaged over B)?
  • Interaction A×B: does the effect of A depend on B? If significant, interpret simple effects rather than main effects; the interaction plot shows non-parallel lines.

Type III sums of squares

With unequal cell sizes (usual in clinical data), sequential (Type I) SS depend on the order of factors. Type III SS test each effect adjusted for all others, matching SPSS default output.

\[\eta_p^2 = \frac{SS_{effect}}{SS_{effect}+SS_{error}}\]

Repeated-measures ANOVA

Purpose: compare means of the same subjects measured at 3 or more time points (e.g. SBP at baseline, 4, 8, 12 weeks).

Data layout

Wide format: one row per subject, one column per time point. Select the columns in time order.

Assumptions

  • Normality of residuals.
  • Sphericity: variances of differences between all pairs of time points are equal. Tested by Mauchly's test. If violated (p < 0.05), use the Greenhouse-Geisser correction, which multiplies the df by ε (≤ 1).

Formula

\[F = \frac{SS_{time}/(k-1)}{SS_{error}/[(n-1)(k-1)]}\qquad \varepsilon_{GG} = \frac{\left(\sum\lambda_i\right)^2}{(k-1)\sum\lambda_i^2}\]

Background

Total variability is partitioned into between-subject variation (removed, as each subject is his/her own control), time effect, and residual error. This makes the design efficient. Post-hoc comparisons use paired t-tests with Bonferroni correction.

If assumptions fail

Friedman test. For missing time points or unequal spacing, PGs should consider linear mixed models.

ANCOVA (analysis of covariance)

Purpose: compare group means while adjusting for a continuous covariate, typically the baseline value. Example: SBP at week 12 between drugs, adjusted for baseline SBP – the recommended analysis for RCTs with a baseline measurement.

Model

\[Y_{ij} = \mu + \tau_j + \beta(X_{ij}-\bar X) + \varepsilon_{ij}\qquad \bar Y_j^{adj} = \bar Y_j - b_w(\bar X_j - \bar X)\]

Assumptions

  • Linear relation between covariate and outcome.
  • Homogeneity of regression slopes (no group × covariate interaction).
  • Normal residuals, equal variances.

Background

ANCOVA removes outcome variation explained by the covariate, reducing error variance and increasing power, and corrects for chance baseline imbalance. It is more powerful than analysing change scores.
